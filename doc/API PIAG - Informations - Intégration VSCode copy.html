L'offre API PIAG est en cours de construction.
Intégration dans VSCode
1- Installer l'extension "Continue - Codestral, Claude, and more" (https://www.continue.dev/) depuis l'onglet "Extensions" (barre verticale
gauche)
Warning
Tests effectués sur VSCode 1.99.3 avec la version 1.0.3 de cette extension.
2- Modifier le fichier de configuration "config.yaml" qui se trouve pour une installation windows sous "C:\Users\prenom.nom\.continue"
Note
Remplacer "sk-xxxxx" par une apiKey valide
name: Local Assistant
version: 1.0.0
schema: v1
models:
- name: MTE-preprod-mistral-medium-latest
provider: mistral
model: mte-api-piag-mistral-medium-latest
apiKey: sk-xxxxx
apiBase: https://preprod.api.piag.e2.rie.gouv.fr/
context:
- provider: code
- provider: docs
- provider: diff
- provider: terminal
- provider: problems
- provider: folder
- provider: codebase
3- cliquer sur l'onglet "Continue" (barre verticale gauche) et sélectionner l'assistant local configuré "MTE-preprod-mistral-medium-latest"
