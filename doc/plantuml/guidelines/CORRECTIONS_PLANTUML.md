# Exemples de Corrections PlantUML (Avant -> Apres)

Ce document montre comment corriger les erreurs PlantUML courantes.

---

## Correction #1 : Alias avec caracteres speciaux

### AVANT (avec \n dans l'identifiant)
Le caractere \n rend difficile la reference.

### APRES (avec alias simple)
Utiliser un alias court et mettre le formatage dans la note.
