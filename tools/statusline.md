La statusLine affichera maintenant des informations détaillées en temps réel :

  - Modèle : Le nom du modèle utilisé (ex: Sonnet 4.5)
  - Barre de progression : Visualisation de l'utilisation du context window
  - Tokens : Total utilisé / taille maximale du context
  - Tokens restants : Espace disponible dans le context window
  - Contexte actuel : Tokens du contexte en cours
  - Entrées/Sorties : Tokens d'entrée 📥 et de sortie 📤
  - Cache : Stats de cache avec lecture/écriture (si utilisé)
  - Économies : Coût économisé grâce au cache
  - Coût total : En USD
  - Temps écoulé : Durée de la session
