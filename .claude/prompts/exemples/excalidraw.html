Instructions d'utilisation

1. Copiez le contenu ci-dessus dans un fichier avec l'extension .md ou .excalidraw
2. Ouvrez le fichier dans Excalidraw ou dans Obsidian avec le plugin Excalidraw
3. Modifiez les diagrammes selon vos besoins

Types de formes disponibles :

  • rectangle - Rectangle
  • ellipse - Ellipse/Cercle
  • diamond - Losange (pour décisions)
  • cylinder - Cylindre (pour bases de données)
  • arrow - Flèche
  • line - Ligne
  • text - Texte

Propriétés principales :

  • strokeColor - Couleur du contour
  • backgroundColor - Couleur de remplissage
  • fillStyle - Style de remplissage (solid, hachure, cross-hatch)
  • strokeWidth - Épaisseur du trait
  • roughness - Niveau de "dessin à la main" (0-2)
  • opacity - Transparence (0-100)
``

Pour utiliser ces diagrammes :

1. Copiez tout le contenu ci-dessus
2. Enregistrez-le dans un fichier texte avec l'extension .md (par exemple diagrammes.md`)
3. Ouvrez-le dans un éditeur compatible comme :
- Excalidraw (en ligne)
- Obsidian avec le plugin Excalidraw
- VS Code avec l'extension Excalidraw

Les diagrammes incluent :


  • Un flux de processus simple

  • Une architecture de base de données

  • Un diagramme de réseau

  • Un processus métier avec décision

Vous pouvez modifier les couleurs, positions, et formes selon vos besoins !
