Description de l'application

  • Numéro d'affaire du pôle ministériel : AFF1108
  • Statut : En production
  • Domaines / sous-domaines :

  • Descriptif :

    Le site web aires-captages.fr vise à centraliser et à diffuser toutes les données liées aux aires d’alimentation de captages (AAC) en France. Il s’agit d’un site participatif reposant sur les échanges de données entre acteurs de la thématique.
