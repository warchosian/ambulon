Description de l'application

  • Numéro d'affaire du pôle ministériel : AFF1177
  • Statut : En production
  • Domaines / sous-domaines :
    • Risques technologiques / Pollutions atmosphériques et terrestres
    • Eau, milieux aquatiques / Services publics d'eau et d'assainissement
    • Eau, milieux aquatiques / Installations classées pour la protection de l'environnement
  • Famille d'applications : Applications métiers répondant à une politique publique ou à une mission du service
  • Descriptif :

    Application permettant de traiter les données d’émissions (GEREP ou GIDAF) pour la production de jeux de données millésimés et des rapports grands publics sur les émissions polluantes.

  • Enjeux :

    - importer les données GEREP/GIDAF (codes d’accès nécessaires) ;
    - repérer les anomalies dans les données déclaratives ;
    - bancariser les retraitement des données ;
    - générer des données millésimées consolidées des émissions polluantes ;
    - générer des rapports grands publics sur un territoire et un millésime donné.

  • Accessibilité numérique : 10 % — Non conforme
  • Issue d'une obligation : Européenne

    Précisions sur cette obligation :

    Obligation de rapportage des émissions polluantes (contribution aux Etat des lieux / SDAGE).

  • Portée géographique de l'application : Nationale

    Précisions sur cette portée géographique :

    Outre-mer inclus. Application actuellement mono-poste en cours de passage à l’échelle dans le cadre de la mission connaissance avec migration sur un site web partagé.

  • Fonctions de l'application :
    • Collecte
    • Concentration
    • Valorisation
    • Diffusion
  • Environnement d'accès : Linux

France Nation Verte

  • Application figurant (ou devant figurer) dans la Cartographie numérique pour la transition écologique
  • Thématiques / sous-thématiques :
    • Consommer / Économie circulaire (Volet déchets des livrables grand public)
    • Préserver / Risques et rejets de polluants (Volets atmosphériques & eau)
  • Catégorisation de l'application :
    • Service numérique / SI métier cœur
  • État des lieux : Abouti

    Précisions sur cet état des lieux :

    Application fonctionnelle et partagée dans le cadre de la mission connaissance.
