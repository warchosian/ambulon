# Ambulon

Un projet simple pour afficher 'Hello Ambulon !' avec la version courante.

## Installation

1. Cloner le dépôt.
2. Installer les dépendances avec Poetry :
   ```bash
   poetry install
   ```
3. Activer l'environnement virtuel :
   ```bash
   poetry shell
   ```

## Utilisation

Exécutez la commande suivante pour afficher le message de salutation :
```bash
ambulon
```

## Développement

- Utilisez `poetry run cz commit` pour créer des commits standardisés.
- Utilisez `poetry run cz bump` pour gérer les versions.
